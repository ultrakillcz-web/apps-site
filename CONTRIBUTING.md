# Contribuindo para o AppsGroup Site

Obrigado por considerar contribuir para o nosso projeto! 

## Como Contribuir

1. Fork o repositório
2. Crie uma branch para sua feature (`git checkout -b feature/MinhaFeature`)
3. Commit suas mudanças (`git commit -m 'Adiciona alguma feature'`)
4. Push para a branch (`git push origin feature/MinhaFeature`)
5. Abra um Pull Request

## Padrões de Código

- Use TypeScript para todo o código
- Siga as configurações do ESLint
- Use commits semânticos (feat, fix, docs, etc.)
- Escreva mensagens de commit em português

## Rodando Localmente

```bash
npm install
npm run dev
```

## Reportando Bugs

Use as issues do GitHub para reportar bugs. Inclua:

- Descrição clara do problema
- Passos para reproduzir
- Comportamento esperado vs atual
- Screenshots se aplicável

## Sugestões de Features

Abra uma issue descrevendo:

- O problema que a feature resolve
- Como você imagina que deve funcionar
- Exemplos de uso
